# Inventory Warehouse Management System

A complete full-stack Inventory and Warehouse Management System.

## Included Features
1. Dashboard
2. Product Management (Add/View/Edit/Delete)
3. Category Management (Add/View/Edit/Delete)
4. Supplier Management (Add/View/Edit/Delete)
5. Warehouse Management (Add/View/Edit/Delete)
6. Inventory Management (Add/View/Update/Delete)
7. Purchase / Incoming Stock Management
8. Sales / Outgoing Stock Management
9. Automatic Low Stock Monitoring
10. MySQL Database Integration
11. Node.js + Express REST API
12. Web Frontend compatible with VS Code Live Server

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL
- Frontend hosting: VS Code Live Server

## Quick Start
1. Import `database/schema.sql` into MySQL Workbench.
2. Edit `backend/.env` with your MySQL password.
3. Open terminal:
   ```bash
   cd backend
   npm install
   npm start
   ```
4. Open `frontend/index.html` with VS Code.
5. Right-click `index.html` -> **Open with Live Server**.

Backend: http://localhost:5000
Frontend: normally http://127.0.0.1:5500

## Important
Keep the backend terminal running while using the frontend.
